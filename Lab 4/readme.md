**Introduction**

This project is a simple JavaScript quiz game that runs entirely within the web browser's developer console. It demonstrates core JavaScript concepts including arrays, loops, conditionals, functions, and user input/output handling.


**Features**

  1.Interactive: Uses prompt() to ask questions and alert() to provide feedback.
  
  2.Case Insensitive: Inputs are processed using .toLowerCase() and .trim() so "Paris", "paris ", and "PARIS" are all accepted as correct.
  
  3.Score Tracking: Calculates and displays the user's score at the end of the game.
  
  4.Pure JavaScript: No HTML or DOM manipulation required.


**How To Run**
  
  1.Open any web browser (Chrome, Firefox, Edge, etc.).
  
  2.Right click and inspect
  
  3.Copy quiz.js and paste it into console.
  
  5.Press enter.
  
  6.Quiz will start immediately


**Learning Outcomes**

This assignment helps us learn:

  1.Arrays & Objects: Storing structured data.
  
  2.Loops: Iterating through question sets.
  
  3.Functions: Encapsulating game logic.
  
  4.Input Validation: Sanitizing user text input.
